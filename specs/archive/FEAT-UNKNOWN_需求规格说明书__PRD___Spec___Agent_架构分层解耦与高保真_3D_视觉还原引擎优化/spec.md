## 1. 背景与痛点根因分析 (Problem Statement & Root Cause)

在上一版将 `input/IMG_7410.JPG` 还原为 `output/presentation_IMG_7410.pptx` 的执行中，Slide 01（问题分析与解决路径）与原图产生了显著的视觉保真度差距。经复盘，问题本质并非单纯的坐标微调问题，而是 **Agent 工程架构设计缺陷（70%）与模型 3D 几何抽象降维（30%）** 共同作用的结果：

```
【原有缺陷架构: 混淆底座与业务】          【重构后架构: 三层解耦 Tri-Layer】
┌────────────────────────────────┐     ┌────────────────────────────────┐
│ 强行将 3D 透视书本降维为 2D 矩形 │ ──▶ │ Layer 1: 纯净 3D 空间艺术底座  │
│ 破坏 3D 空间深度 / 比例臃肿失衡 │     │ Layer 2: 独立书法艺术与光球浮层 │
│ 缺乏视觉闭环自验机制           │     │ Layer 3: 100% 原生可编辑业务卡片│
└────────────────────────────────┘     └────────────────────────────────┘
```

1. **教条化执行规则导致视觉降维**：`AGENTS.md` 要求“100% Native Shapes”，Agent 机械地将复杂的 3D 透视书本与倾斜顶板抹平成两个 2D 平面大色块，视觉质感严重坍塌。
2. **底座与业务层未解耦**：未区分“不可编辑的 3D 空间艺术底座”与“必须自由编辑的业务文案/数据指标”。
3. **空间栅格与呼吸感失真**：卡片纵向过度拉伸（y 从 175 占到 930），导致页面下半部极度拥挤，丧失了咨询级 Deck 的高级留白感。
4. **缺少视觉比对闭环**：仅依赖代码运行状态和 Shape 列表自验，缺乏渲染图像素级比对。

## 2. 核心目标与架构重塑 (Core Objectives & Architecture)

### 2.1 引入三层解耦渲染架构 (Tri-Layer Decoupling Architecture)
- **Layer 1: 纯净 3D 空间透视基座层 (Visual Artwork Layer)**
  - 承载等轴 3D 透视书本底座（倾斜书脊、立体厚度、顶面高光、地面柔光漫反射投影、6 组中缝装订活页环）。
  - **绝不包含任何业务文字**，作为纯净无字的高精度渲染图层，提供 100% 的 3D 空间视觉冲击力。
- **Layer 2: 独立书法艺术与光效浮层 (Artistic Motif Layer)**
  - 承载中缝“破局”书法毛笔字、3D 渐变透亮光球与运动速度线，作为独立透明 PNG 浮层。
- **Layer 3: 100% 原生可二次编辑业务层 (Native Editable Content Layer)**
  - 承载 6 组业务卡片容器、药丸标签、标题横幅、金句展开双翼、所有业务数据指标（60%、15%、22%、45天、18%、7天、3%、85%、30天内、72小时内）。
  - 严格保持 **左侧卡片文案左对齐、右侧卡片文案右对齐** 的镜像张力。

### 2.2 重构 0-1000 宏观蓝图栅格 (Strict Grid & Spatial Ratio)
- **收拢 3D 书本垂直范围**：书本高度约束在 `y: 200 ~ 800`，保留顶部金句与底部各 20% 的充裕呼吸留白。
- **卡片精致化比例**：单张白卡片高度控制在 `h: 120` 左右，恢复原图修长精致的悬浮质感。

### 2.3 升级 Agent SOP 规范 (`AGENTS.md`)
- 明确定义“3D 空间底座”与“业务图层”的边界准则，避免未来 AI Agent 再次陷入“为了原生而抹平复杂 3D 艺术”的教条主义。

## 3. 用户故事与验收标准 (User Stories & Acceptance Criteria)

### US-1: Slide 01 纯净 3D 透视底座与高保真图层生成
- **AC 1.1**: 生成纯净无任何业务文字的 3D 透视书本底座图层（包含左侧群青蓝 3D 封面、右侧砖红 3D 封面、立体顶板厚度、中缝活页孔环与地面真实漫反射阴影）。
- **AC 1.2**: 提取无背景、边缘无杂色的独立透明“破局”书法 + 3D 光球资产。
- **AC 1.3**: 底座与浮层图层严密贴合，无任何白边、锯齿或底图文字重影。

### US-2: 业务卡片 100% 原生吸附与镜像对齐排版
- **AC 2.1**: 6 组卡片（左 3 右 3）采用原生 PowerPoint 白底圆角矩形，精准吸附于 3D 底座的左右开页之上。
- **AC 2.2**: 左侧 3 组卡片药丸标签位于左上角，卡片正文严格采用 **左对齐**。
- **AC 2.3**: 右侧 3 组卡片药丸标签位于右上角，卡片正文严格采用 **右对齐 (Right-aligned)**，与左侧形成向心聚拢的平衡美感。
- **AC 2.4**: 卡片内所有数字指标（60%、15%、22%、45天、18%、7天、3%、85%、30天内、72小时内）采用独立颜色高亮加粗，且 100% 可在 PowerPoint 中直接双击修改。

### US-3: 顶部横幅与辅助装饰细节还原
- **AC 3.1**: 顶部金句横幅 `"渠道渗透不足导致增量乏力..."` 两侧还原向外展开的浅蓝渐变光效双翼（Wings Accent）。
- **AC 3.2**: 3D 书本上方的两条细长定位横幅（`整体销售渠道渗透不足...` 与 `实施精准拓客增效...`）采用原生圆角形状与定位圆点，文字 100% 原生可编辑。

### US-4: 演示文稿合并与工程资产归档
- **AC 4.1**: 重新生成合并的最终演示文稿 [`output/presentation_IMG_7410.pptx`](file:///Users/feng.liu/workspace/output/presentation_IMG_7410.pptx)，包含 Slide 01 与 Slide 02。
- **AC 4.2**: 更新 `AGENTS.md` 规范与 SDD 变更日志，将三层解耦最佳实践固化为沉淀资产。

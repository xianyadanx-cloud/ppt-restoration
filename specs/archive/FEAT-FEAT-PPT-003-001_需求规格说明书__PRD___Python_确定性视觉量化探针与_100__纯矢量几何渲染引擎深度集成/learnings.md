# LEARNINGS-FEAT-PPT-003-001 ｜ 实战经验复盘沉淀

## 🎯 核心认知跃迁

1. **从“经验猜测”到“确定性像素量化探针”**：
   - 传统大模型生成常出现 20~90px 的系统性坐标漂移与字体大小偏差。
   - 通过建立 16:9 画布自动裁剪、像素级 RGB 比色探针以及物理字阶公式（$\text{pt} = \text{height\_px} \times 0.667$），实现精确度量与还原。

2. **100% 纯原生矢量几何体系的通用性**：
   - **Slide 01（立体折页书本）**：采用 `add_polygon` 自由多边形 + 倾斜渐变（$\pm 7.0^\circ$）+ 原生艺术字与正圆球体拼装，彻底告别位图。
   - **Slide 02（拟物板夹与复合卡片）**：采用分层底板拼装拟物板夹 + 原生表格隔行上色 (`row_bg_colors`) + 珍珠滑块进度条 (`gradient_colors` + `node_glow`) + 复合 KPI 指标卡，保持 0 PICTURE 位图的纯原生可编辑体验。

### 📌 [L-01] 拟物板夹与原生表格进度条的精细对齐
- **问题现象**：原生 PPT 表格内部无法直接内嵌图形进度条，容易导致进度条与表格文字行高错位。
- **根本原因**：PPTX 内部表格单元格与独立图形不在同一个流式布局中。
- **修复方案与最佳实践**：
  - 在表格第 4 列单元格保留空白占位。
  - 根据表格在 0-1000 空间中的起始坐标与行高间距，以公式精确计算出每一行中心点 `top_pos = table_top + header_h + row_h * idx + center_offset`。
  - 使用 `builder.add_progress_bar` 叠放在第 4 列单元格中央。
- **可复用性**：高，适用于所有仪表盘与战役完成度表格页面。

### 📌 [L-02] 3 联复合 KPI 卡片的视觉层次构建
- **问题现象**：常规 KPI 卡片容易扁平单调，缺乏视觉焦点。
- **修复方案与最佳实践**：
  - **顶部**：外凸白色药丸徽章（带细描边与主题色文字），营造卡片标签感。
  - **中部**：巨幅核心数值（21~24pt Bold），深色大字形成第一视觉锚点。
  - **底部**：实体色块胶囊（白字 + 主题色底色），突出缺口或增幅预警。
  - **卡片间**：使用渐变圆形箭头徽章（`➔`），清晰表达业务流转逻辑。
- **可复用性**：极高，适用于所有数据指标汇总与效能透视幻灯片。
